# Phase 3: continuous UCB execution

Run `python3 main.py` for an offline summary. To consume remaining group allowance,
run `python3 main.py --online`. Add `--auto-tune` for optional full-horizon rollout
tuning every 200,000 newly saved pulls, or `--no-auto-tune` to use fixed UCB.
`--limit N` caps additional successful pulls; `--target-total N` caps the absolute
group counter. Omitted values use config.py, whose limits default to None (all
remaining). The group-wide cap includes all earlier phases.

All settings, including model multiplier, request pacing, retry policy, worker
budget and CVaR allowances, are in config.py. Passwords are prompted privately.
First Ctrl-C/SIGTERM stops after saving the in-flight response. A second signal
can force exit. Restart with the same database/account to recover durable pending
state; do not create another driver or change request IDs to bypass it.

The entry uses aggregate model loading and bounded progress output, not a list of
all historical rows. The supplied cloud helper is unchanged. Detailed [runtime
instructions](../README.md) and [tuning theory/limitations](../docs/tuning.md) live
at the repository root. The notebook offers the same controls.

`explain.py` is a separate offline research/report script. Its historical replay
uses each row's recorded UCB coefficient, including automatic changes. It still
loads full history for its extensive research analyses; do not run it concurrently
with the continuous driver on a memory-constrained machine. Existing results CSVs
are historical snapshots and are not automatically regenerated by live runs.

After the run, `export_results.py` writes the committed record of the live experiment to
`results/`: every pull (`final_pulls.csv.gz`), every tuning decision (`tuning_decisions.json`)
and a summary with integrity checks, stages and per-arm intervals (`final_summary.json`). It
only reads the database. `checklocalstatus.py` reports a run's progress, timing spread and
tuning decisions from the local database and event log, also without network access.
